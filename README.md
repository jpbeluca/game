# ⛏️ Craft Breaker

Um quebra-blocos (Breakout) estilo **Minecraft**, feito em um único arquivo HTML.
Joga no celular (toque) e no PC (mouse/setas). Sem servidor, sem instalação.

## ▶️ Jogar online

Link público (GitHub Pages):

**https://jpbeluca.github.io/game/**

> Se o link ainda não abrir, é porque o GitHub Pages precisa ser ligado uma
> única vez nas configurações do repositório (veja abaixo). Depois disso, é só
> abrir o link no celular e jogar.

## 🎮 Como jogar

- **Celular:** arraste o dedo para mover a tábua. Toque para soltar a bola.
- **PC:** mouse ou setas ← → para mover; barra de espaço para soltar a bola.
- 💣 Blocos de **TNT** explodem os vizinhos.
- 💎 Diamante e 🪙 ouro são mais resistentes e valem mais pontos.
- Limpe todos os blocos para passar de nível.

## 🖼️ Foto de fundo (Bento)

Coloque a foto em `assets/bento.jpg`. O jogo aplica automaticamente um
tratamento estilo Minecraft (pixelização + posterização + tom de céu +
vinheta). Sem a foto, o fundo é um céu azul de Minecraft.

## ⚙️ Ligar o GitHub Pages (uma vez só)

1. No GitHub, abra **Settings → Pages**.
2. Em **Source**, escolha **Deploy from a branch**.
3. Selecione a branch `claude/mobile-game-no-hosting-LS04e` e a pasta `/ (root)`.
4. Salve. Em ~1 minuto o link acima fica no ar.
